# Research homepage versions saved before publication

- `sns-original.html`: Original published SNS page, taken from commit `a7bae2828b26361057978601228797a2c31b5410` before the research homepage redesign.
- `research-draft.html`: Research homepage draft, saved immediately before the October 11 background and publication edits. Includes the SLACS 2026 slide link.

These files preserve the historical HTML unchanged. Their relative links refer to the original `sns/` directory. Restore the desired file to `sns/index.html` to use it as a page again.

The `_backups/` directory is an archive, excluded from normal Jekyll publishing. The copies are deliberately committed to Git despite the local ignore rule so they remain recoverable through GitHub.
