圏論は笑わない。

圏論を，万能の抽象化装置としてではなく，証明・計算・意味論の形を静かに観察するための言語として読むためのメモ。 ここでは主に，代数的意味論や領域理論に入ってくる最小限の圏論的道具を整理します。

  • 目標: 関手，随伴，モナド，余代数を，論理との接続が見える粒度で読む。
  • 関心: 構文と意味論の対応，反射原理の抽象化，固定点・循環性の扱い。
  • 方針: 定義を過剰に一般化せず，具体例から必要な分だけ引き上げる。

抽象的証明可能体系動物園 (Zoo of APS)

APS は Abstract Provability System の略称として扱っています。 証明可能性述語や反射原理を，算術の内部だけでなく，抽象的な代数・順序・圏論的構造の上で眺めるための分類表です。

TeX で出力した PDF と，動物園形式の入口は APS-ZOO にまとめています。 トップページからも直接たどれるようにしてあります。

Class Core idea Typical questions
Hilbert-Bernays-Lob type 導出可能性条件と Lob 型原理を中心にした体系。 どの条件から固定点・反射・不完全性が立ち上がるか。
Modal / algebraic type 様相演算子や代数的演算として証明可能性を表す体系。 Magari 代数的な見方と一般の抽象代数論理の距離。
Coalgebraic type 状態遷移・観測・循環性から証明可能性を読む体系。 自己言及や循環的証明をどの構造で扱うか。
Domain-theoretic type 近似，安定性，順序構造を使って意味を構成する体系。 不動点や情報増大が証明可能性にどう反映されるか。

この動物園は完成表というより，体系同士の変換，包含，反例を置いていくための作業場です。

安定領域理論 (Stable Domain Theory) の勉強記事

安定領域理論を，表示的意味論だけの話としてではなく，論理の不動点・近似・証明可能性を考えるための道具として読むメモです。 まずは Berry 安定性，安定順序，dI-domain の関数空間を中心にした専門記事を置きました。

  • Article: 安定領域理論: Berry stability, stable order, and dI-domains
  • Focus: dcpo，compact approximation，stable functions，parallel-or の非安定性。
  • Next: 固定点定理，再帰的定義，証明可能性・反射・自己言及との接続を追記予定。

可算 Rosser 型文と APS モデルの構造論について

Rosser 型の自己言及文を可算族として扱うとき，何を「可算個ある」と呼ぶのかを分けておかないと， 同じ理論内の独立性，拡大列に沿った独立性，抽象モデル上の自由度が混ざってしまいます。 その整理のための専門記事を追加しました。

  • Article: 可算 Rosser 型文: 独立性・塔・APS 表現
  • Focus: Rosser の trick，Rosser provability，countable family の三つの読み分け。
  • Caution: 「同一理論上で互いに独立な可算族」と「拡大列に沿った可算族」は別問題として扱います。
  • Next: 反射原理，代数的表示，順序表示の間で保存される性質を比較する予定です。

作業上の中心問題は，「可算に多くの自己言及を許したとき，証明可能性構造はどこまで自由で，どこから強制されるのか」です。
